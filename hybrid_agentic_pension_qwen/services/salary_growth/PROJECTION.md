# 임금 재귀 예측

현재 모델은 향후 3개 연도의 전년 대비 임금상승률 산술평균을 예측한다.
`is_cagr`는 계속 `false`이며 모델이나 학습 타깃을 변경하지 않는다.

`recursive_constant_annual_rate_scenario`는 이 값을 각 3년 구간의 일정한
연간 상승률로 가정하는 시나리오 방식이다. 산술평균으로 실제 연도별
상승률이나 CAGR을 복원하는 것은 아니며, 장기 예측 정확도는 검증 전이다.

1. 현재 나이, 연봉, 직종으로 모델을 호출한다.
2. 최초 구간에 입력값이 있으면 해당 값을 사용한다. 자동 추정 후 입력칸에
   채워진 값과 사용자가 직접 수정한 값 모두 동일하게 처리한다.
3. 이후 구간은 갱신된 나이와 계산된 연봉으로 다시 모델을 호출한다.
   모델 예측과 나이별 곡선을 기존 가중치 설정에 따라 혼합한다.
4. 구간 안에서는 매년 같은 상승률로 연봉을 갱신한다. 마지막 구간은
   은퇴까지 남은 기간만 계산한다.

DB는 이 연봉 경로로 예상 급여를 계산한다. DC는 연봉 변화에 비례해
사업주 납입액을 조정하고 개인 추가 납입액은 고정한다.
연결 끊김이나 일시적 서버 오류는 같은 구간의 입력으로 최대 3회 요청한다.
재시도는 새 연결로 수행한다. 인증·입력 오류는 반복 요청하지 않는다.
예측 API가 중간에 실패하면 성공한 구간은 유지하고 마지막 성공 구간의
최종 적용 상승률(수동 입력·커브 보정 포함)을 남은 기간에 고정 적용한다.
이후 구간에서는 API 호출이나 커브 재보정을 하지 않는다. 반환 결과의
`continuation`과 보고서에 시작 나이 및 적용률을 표시한다.
첫 구간부터 실패해 성공한 구간이 없으면 DB·DC 보고서 생성을 중단한다.
실패한 분석을 다시 시작하면 새 요청에서 모델 예측을 다시 시도한다.

## 2026-09-06 실험 및 연결

모델 서버는 raw CatBoost 출력을 유지한다. 앱 predictor는 `calibration.json`의
intercept와 slope를 한 번 적용하며 projector의 `raw_catboost_growth`에는
보정 전 출력, `catboost_growth`에는 보정 후 출력(또는 수동 입력)을 기록한다.
요청/응답 schema와 기존 route는 유지한다.

`blend_weights.json`은 그룹별 비중 또는 연속 감쇠 설정을 담는다.
비중은 3년 블록 시작 horizon에서 결정하여 블록 동안 유지한다.
명시적인 첫 구간 입력은 비중과 관계없이 그대로 적용한다.
artifact가 없는 이전 버전은 기존 감쇠 설정과 무보정 동작을 유지한다.

이번 실험은 2015/2016 origin에서 후보를 탐색하고 2017 origin에서 구조를
비교했다. 선택에 사용한 실제 임금은 2020년까지만이며 2021–2024 endpoint는
후속 평가에 사용했다. 선택된 비중은 CatBoost 1.0, Age Curve 0.0이다.
Age Curve 구현을 제거한 것은 아니며 현재 데이터에서 결합 이득이 없었다.
가중치 선택은 최대 5년까지만 가능했고, 10/15년 실제 성능은 자료가 없다.
따라서 장기 경로의 `provisional`은 true를 유지한다.

고정 split의 최종 모델과 각 origin별 모델은 서로 다르다. 고정 split은 기존
train ≤2018 / validation 2019–2020 / test 2021을 유지한 벤치마크이고,
3년 정답의 달력이 겹친다. 엄격한 과거 시점 평가는 별도 rolling 결과를 본다.

실험/백업/평가: `modeling/training_runs/lifecycle_v1/`.
원격 서비스 반영 시 모델 서버의 .cbm과 앱의 metadata/calibration/curve/weights를
함께 배포해야 한다. 로컬 검증은 원격 운영 서버를 변경하지 않는다.
